# AI review log

Every mistake an AI agent made that review or measurement caught: what it did, why it was wrong,
and the rule added to `CLAUDE.md` (or the code) so it does not happen again.

| Date | Where | What the AI did | Why it was wrong | Rule / fix |
|---|---|---|---|---|
| 2026-10-06 | `LoginPage` (planned) | Expected a **Login** button and the Desk at **/app** | ERPNext v16 shows **Continue** and lands on **/desk**; the AI wrote from older versions | Locators come from the real page's accessibility tree, read before writing (CLAUDE.md rule 5) |
| 2026-10-06 | Seed check of a taxed invoice | Set `taxes_and_charges` through the API and expected tax 20.00 | The API does not copy a template's lines (the screen does); tax was 0.00 | `api.salesTaxRows(template)`; CLAUDE.md rule 7 |

| 2026-10-06 | Seed: QA Testing sidebar | Created a **Workspace Sidebar** record | ERPNext v16.50 made those a read-only archive; a module's sidebar is customised with **Custom Sidebar** | Probe the running version before using an API from memory |
| 2026-10-06 | Seed: setup wizard | Called the setup wizard with the default 30 s request timeout; it passed on the first site | On a brand-new site the wizard took longer: the seed failed. | 2026-10-06 | Retail POS India: number pad | Started a new amount only when a *different* payment mode was selected | Tapping the same mode again kept adding to the old amount; a cashier expects a fresh amount. | 2026-10-06 | POS check script | Read the amount right after a tap, and tapped before the payment panel had drawn | The screen updates a moment later: results looked flaky | Wait for the expected result (`expect(...).toHaveText`), never read immediately (CLAUDE.md rule 6) |
